### 2) Medium: In-memory filters losing indexes ⚠️ ACKNOWLEDGED BUT KEPT
I tried `.where('isActive').equals(true)` but Dexie/TypeScript throws:
`error TS2345: Argument of type 'boolean' is not assignable to parameter of type 'IndexableType'`

Dexie doesn't support boolean values in `.equals()` - only strings, numbers, dates, and arrays.
The `.filter()` approach is the correct pattern for boolean fields in Dexie.

For this app's scale (handful of starters, dozens of bakes), in-memory filtering is fine.
If scale becomes a concern, we could:
- Store booleans as 0/1 integers (schema change)
- Or use compound indexes like `[isActive+name]` and query with `.where('[isActive+name]').between([1, ''], [1, '\uffff'])`

For now, `.filter()` is the pragmatic choice.

### 3) Medium: Notifications without permission check ✅ FIXED
